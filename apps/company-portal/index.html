🖥️ 바탕화면에 설치하기

이 브라우저에서는 자동 설치 팝업이 뜨지 않아요. 아래 방법 중 하나를 그대로 따라해주세요. (한 번만 설치하면 다음부터는 바탕화면·시작메뉴 아이콘으로 바로 열립니다)

💻 Windows — Edge

  1. 주소창(화면 위쪽, 인터넷 주소 적는 칸) 맨 오른쪽을 보면 모니터 모양 아이콘이 있는지 확인하세요. 마우스를 올리면 "이 사이트를 앱으로 설치"라고 표시됩니다.
  2. 그 아이콘이 있으면 클릭 → 팝업창에서 [설치] 버튼 클릭 → 끝!
  3. 아이콘이 안 보이면: 브라우저 오른쪽 위 점 3개(⋯) 클릭 → [앱] 메뉴 → [이 사이트를 앱으로 설치] 클릭 → [설치] 버튼 클릭

💻 Windows — Chrome

  1. 주소창 오른쪽 끝의 모니터 모양(⊕) 설치 아이콘 클릭 → [설치] 버튼 클릭
  2. 아이콘이 없으면: 브라우저 오른쪽 위 점 3개(⋮) 클릭 → [도구 더보기] → [바로가기 만들기...] → "창으로 열기" 체크박스 선택 → [만들기] 클릭

📱 안드로이드 — Chrome

  1. 오른쪽 위 점 3개(⋮) 메뉴를 누르세요.
  2. 목록에서 [앱 설치] 또는 [홈 화면에 추가]를 누르고, 나오는 팝업에서 [설치] 또는 [추가]를 누르세요.

📱 아이폰/아이패드 — Safari

  1. 화면 아래(또는 위) 공유 아이콘(네모 안에 위쪽 화살표)을 누르세요.
  2. 메뉴를 아래로 내려 [홈 화면에 추가]를 누르세요.
  3. 오른쪽 위 [추가]를 누르면 완료됩니다.
