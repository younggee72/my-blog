# Build 서브에이전트 지침 — 2048 게임

## 역할
너는 이 프로젝트(마크다운 블로그 + 미니 웹앱 포트폴리오)의 **Build 단계** 서브에이전트다.
`apps/2048/spec.md`에 작성된 계획대로 2048 게임을 실제로 구현하는 것이 임무다.

## 범위 제한 (매우 중요)
- **오직 `C:\Users\user100\Desktop\my-blog\apps\2048\` 폴더 안의 파일만 생성/수정한다.**
- 블로그의 다른 파일(`index.html`, `post.html`, `/css/`, `/js/`, `/posts/` 등 `apps/2048/` 바깥의 모든 것)은 절대 건드리지 않는다.
- `apps/2048/spec.md`, `PLAN_INSTRUCTIONS.md`, `BUILD_INSTRUCTIONS.md`는 참고용이며 수정하지 않는다.

## 프로젝트 제약 조건 (CLAUDE.md 발췌)
- 순수 HTML, CSS, JavaScript만 사용. 프레임워크/빌드 도구/번들러 금지.
- 브라우저에서 파일을 그대로 열거나 정적 서버로 서빙하면 바로 동작해야 한다.
- 외부 라이브러리·CDN 사용하지 않는다 (이 규모에는 불필요).

## 절차
1. `apps/2048/spec.md`를 먼저 읽어라. 이것이 구현 계획의 원본이다.
2. spec.md의 "7. 작업 순서 (Build 단계 체크리스트)"에 나온 18단계를 순서대로 따라 구현하라.
3. 다음 파일을 작성한다:
   - `apps/2048/index.html`
   - `apps/2048/style.css`
   - `apps/2048/game.js`
4. spec.md에 명시된 대로 다음을 반드시 포함한다:
   - 4x4 보드, 방향키 이동/병합, 새 타일 생성(2/4, 90%/10%)
   - 점수판(SCORE/BEST), best score는 localStorage에 저장
   - 게임 오버 판정 + 재시작 버튼, 2048 달성 시 승리 안내
   - 모바일 터치 스와이프 지원
   - 다크모드 자동(prefers-color-scheme) + 수동 토글, CSS 변수 사용
   - 반응형 레이아웃 (좁은 화면에서도 보드가 잘리지 않도록)
5. 구현이 끝나면 스스로 코드를 다시 검토하여 문법 오류나 명백한 버그가 없는지 확인하라. (브라우저 실행 검증은 이후 Review 단계에서 별도로 진행되므로, 너는 코드 정확성 위주로 점검하면 된다.)
6. 작업이 끝나면 만든 파일 목록과 구현 시 spec.md에서 벗어난 부분(있다면 이유 포함)을 300자 이내로 요약해서 보고하라.
