# Review 결과 — 현장정산서 자동화 도구 (settlement)

검증일: 2026-08-18
검증 방법: spec.md 대조 코드 리뷰 + 로컬 정적 서버(`python -m http.server`)로 `apps/settlement/index.html`을 띄워 브라우저에서 실제 조작

## 1. spec.md 대조 결과 (통과)

- **데이터 구조**: `state.projectInfo/subcontract/labor/etc/account`, 표별 `nextId` 카운터, `paidAmountTouched` 플래그 등 spec 3.1 구조 그대로 구현됨.
- **파생 계산**: `calcVat`, `calcTotal`, 표1 `balance`, 표2 `total = supply - withholdingTax`, 표3 `total = supply + vat` 모두 spec 3.2 수식과 일치.
- **행 추가/삭제/이벤트 위임**: 표별 `<tbody>` 하나에 `input`/`change`/`click` 리스너를 한 번씩만 등록(이벤트 위임) — spec 3.3과 일치. `paidAmountTouched` 로직도 정확히 구현되어, 결제금액을 직접 수정한 뒤에는 공급가액이 바뀌어도 자동 동기화가 멈춤(브라우저에서 직접 재현 확인).
- **정산 요약 A/B**: 실제 숫자(공급가액 1,000,000 / 표1 700,000 / 표2 공급 300,000·원천세 10,000 / 표3 공급 200,000·부가세 20,000)를 입력해 화면 값과 손계산을 대조한 결과, 요약 A(세금계산서발행금액/매입자료금액/노무비/기타보증서/잔여마진)와 요약 B(기술료=공급가액×5%, 경비, 매입액, 노무비, 잔여금액) 모두 spec 3.5 수식과 정확히 일치.
- **localStorage**: 상태 키(`settlement-app-state`)와 테마 키(`settlement-app-theme`)가 분리 저장되며, 새로고침 후 입력값이 정확히 복원됨을 확인.
- **초기화 버튼**: `confirm()` 확인 후 상태만 빈 템플릿으로 리셋되고 테마 키는 그대로 유지됨을 콘솔에서 재현 확인.
- **엑셀 내보내기**: SheetJS(`xlsx.full.min.js`) CDN이 정상 로드(`typeof XLSX === 'object'`)되고, 내보내기 버튼 클릭 시 콘솔 에러·네트워크 오류 없이 동작. 시트 레이아웃(제목/상단정보/표1~3/요약A·B/계좌정보) 구성이 spec 3.7과 일치.
- **숫자 포맷**: 금액 입력은 `type="text"` + `inputmode="numeric"`이며 focus 시 콤마 제거, blur 시 `toLocaleString('ko-KR')`로 재포맷되는 패턴이 spec 4.2대로 동작.

## 2. 공통 웹앱 규칙 점검 (통과)

- **색상 팔레트**: `apps/settlement/style.css`가 `/css/style.css`와 동일한 `--color-bg`, `--color-bg-secondary`, `--color-text`, `--color-text-secondary`, `--color-accent`, `--color-border`, `--color-code-bg` 값을 자체 정의해 사용. 앱 전용 보조색(`--settlement-*`)도 팔레트 변수를 참조해 구성되어 있고 임의 하드코딩 색상 없음.
- **사용법 안내**: 헤더 바로 아래 `.guide-box`에 4단계 사용법과 "실제 데이터가 아닌 빈 템플릿" 안내 문구가 항상 노출됨.
- **다크모드**: `prefers-color-scheme` + `[data-theme]` 이중 구조로 구현, 토글 버튼(🌙/☀️) 클릭 시 실제로 전환되며 표/카드/버튼/입력 필드 대비 육안 확인 결과 문제없음.
- **모바일 대응**: 375px, 320px 뷰포트에서 표는 `.table-scroll` 컨테이너 내부에서만 가로 스크롤되고(페이지 전체 가로 스크롤 없음, `document.body.scrollWidth === window.innerWidth` 확인), 기본정보/요약/계좌 카드는 1열로 쌓이며 액션 버튼은 폭 100%로 세로 배치됨.
- **민감정보**: 코드 전체에 실제 회사명/거래처/계좌/전화번호 등 하드코딩된 값 없음(전부 빈 값 또는 플레이스홀더 텍스트).

## 3. 브라우저 실동작 검증 (통과)

- 공사명/공급가액 입력 → 부가세·합계 즉시 계산 확인.
- 표1 행 추가 후 공급가액 입력 → 부가세/합계/결제금액 기본 동기화/잔액 계산, 결제금액 직접 수정 후 공급가액 재변경 시 동기화 중단 확인, 행 삭제 확인.
- 표2/표3 행 추가 및 계산, 표3 "×10%" 보조 버튼으로 부가세 자동 채움 확인.
- 각 표 소계가 입력값 변경 시 즉시 갱신됨을 확인.
- 정산 요약 A/B를 손계산으로 대조해 수식 오차 없음 확인.
- 새로고침 후 입력값 복원, 초기화 버튼 동작(테마 유지) 확인.
- 엑셀 내보내기 클릭 시 에러 없이 동작(SheetJS 정상 로드) 확인.
- 표에 행이 0개인 엣지 케이스에서 소계가 0/0/0으로 정상 표시되고 콘솔 에러 없음 확인.
- 전 과정에서 브라우저 콘솔 에러 없음.
