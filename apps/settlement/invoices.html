사용법 — ① 계산서 PDF/이미지/엑셀(.xls, .xlsx)을 업로드하거나 폴더를 연결하면 자동으로 정보를 읽어옵니다. ② "확인 필요" 배지가 붙은 항목은 반드시 클릭해서 값을 확인·수정해주세요(자동인식은 완벽하지 않습니다). ③ 공사명은 자동으로 채워지지 않으니 직접 입력하세요. ④ 같은 공사명끼리 모은 뒤 "이 공사명으로 정산서 생성" 버튼을 누르면 정산서 작성 화면에 협력업체 내역으로 자동 반영됩니다(결제금액은 항상 0에서 시작하며, 실제 지급을 확인하며 직접 입력해야 합니다). 입력한 값과 업로드한 파일은 이 브라우저에만 저장되며(다른 곳으로 전송되지 않음), 실제 거래 데이터가 아닌 빈 템플릿이니 자유롭게 연습해 보세요.

계산서 업로드

PDF(전자세금계산서), 스캔본·스크린샷 이미지, 또는 엑셀(.xls, .xlsx) 파일을 올리면 자동으로 발행일·거래처·사업자등록번호·공급가액·부가세·합계를 읽어옵니다. 스캔 이미지나 임베드 텍스트가 없는 PDF는 인식(OCR)에 다소 시간이 걸릴 수 있습니다(처음 사용 시 한글 인식 데이터를 내려받습니다).

계산서 폴더 연결

세금계산서 PDF/이미지/엑셀(.xls, .xlsx)을 모아둔 폴더를 연결하면, 폴더 안의 파일을 자동으로 목록에 불러와 인식합니다. "폴더 연결"은 이전에 연결했던 폴더를 그대로 이어서 쓰고(크롬/엣지는 권한만 다시 확인하면 됨), "다른 폴더 선택"을 누르면 새 폴더를 고를 수 있습니다. 새로고침 후 다시 연결하면 이미 목록에 있는 파일은 건너뛰고 새로 추가된 파일만 처리합니다.
