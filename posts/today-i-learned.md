# 오늘 배운 것

클로드 코드와 함께 프레임워크 없이 순수 HTML, CSS, JavaScript로 블로그를 만들면서, 세 가지 기술이 각각 어떤 역할을 하는지 정리해봅니다.

## HTML - 뼈대(구조)

HTML은 페이지에 어떤 내용이 어떤 순서로 들어가는지를 정합니다.

- `index.html`: 글 목록이 들어갈 자리
- `post.html`: 글 제목, 날짜, 본문이 들어갈 자리
- 실제 글 목록이나 본문 내용은 처음부터 HTML에 적혀있지 않고, 나중에 JavaScript가 채워 넣습니다.

즉 HTML은 **틀만 만들어두고, 내용은 비워둔 상태**로 시작합니다.

## CSS - 디자인과 테마

CSS는 그 틀을 어떻게 보여줄지 담당합니다.

- 색상, 여백, 글자 크기 같은 값을 `:root` 변수로 한 곳에 모아두면 관리가 쉬움
- 다크 모드는 새로운 디자인을 또 만드는 게 아니라, `data-theme="dark"`일 때 **같은 변수들의 값만 바꿔주는 방식**으로 구현
- 화면이 좁을 때와 넓을 때 다르게 보이도록 하는 반응형도 CSS의 `@media` 규칙으로 처리

## JavaScript - 동작과 데이터 연결

JavaScript는 HTML의 빈 자리에 실제 내용을 채우고, 사용자 동작에 반응하는 역할을 합니다.

- `fetch()`로 `posts/manifest.json`과 각 마크다운(`.md`) 파일을 읽어옴
- 읽어온 마크다운 텍스트를 직접 만든 파서로 `<h1>`, `<p>`, `<strong>` 같은 HTML 태그로 변환
- 변환된 결과를 `innerHTML`로 페이지에 삽입
- 다크 모드 토글 버튼 클릭 같은 사용자 동작을 감지해서 테마를 바꾸고 `localStorage`에 저장

## 정리

> HTML은 무엇을 보여줄 자리인지, CSS는 어떻게 보이는지, JavaScript는 그 자리를 실제 데이터로 채우고 움직이게 만드는 역할을 한다는 걸 직접 만들어보면서 체감했다.

세 가지가 딱 나눠서 각자의 역할만 하니, 프레임워크 없이도 구조가 꽤 명확하게 잡힌다는 점이 인상적이었다.
